# 更新记录

## 0.1.0 — 2026-10-17

首次发布，版本标签 `socks5-v0.1.0`。

- 基于 GOST 3.3.0 的单文件 SOCKS5 部署与中文管理菜单。
- 自定义或安全随机生成用户名、密码和空闲高位端口，强制账号密码认证。
- 可选 TLS 隧道，支持自动生成 IP/域名证书、自定义证书和私有 CA，客户端开启证书及名称校验。
- 导出本机 GOST 配置包，包含所需公钥证书，不导出 VPS 私钥。
- 专用普通账户与 systemd 服务，开机启动、异常退出自动重启。
- 固定版本下载并验证 SHA-256，结构化保存凭据并限制文件权限。
- 配置变更自检、失败恢复，按需添加和清理本工具所属 UFW/firewalld 规则。
- 20 项测试覆盖真实 GOST 认证和转发、TLS 校验、安装管理流程与失败恢复。

支持 Debian 12/13、Ubuntu 22.04/24.04，amd64/arm64。第一版为单实例、单用户、TCP 代理，尚未接入统一工具箱菜单。

验证环境为 macOS arm64，使用真实 GOST 进程；systemd、账户和防火墙操作使用测试替身。尚未完成真实 Linux VPS 上的端到端部署验证。
