# SSH 密钥工具第一版验收

日期：2026-10-10。版本：`sshkeytool 0.1.0`、`vpstools 0.2.9`。

按用户指定，安装及认证修改测试只在 **stone-hk** 完成，系统为 Debian 12、OpenSSH、systemd。连接使用电脑上的 OpenSSH 和已有本地私钥；从 FinalShell 保存的连接元数据核对端口后，将本地 `stone-hk` 别名的旧端口 22 更新为 21919，保存了配置备份。没有通过 FinalShell 发起连接，也没有导出或显示其密码。

## stone-hk 实机流程

| 验证 | 结果 |
| --- | --- |
| 独立安装及 `vpstools run sshkey` | 程序可运行，安装前后 SSH 配置和公钥文件校验值一致 |
| VPS 自动生成 Ed25519 | 保留原公钥，追加新公钥，服务器私钥 0600 |
| 下载到电脑 | 临时目录 0700，私钥 0600，与服务器公钥指纹匹配 |
| 用旧密钥确认新增密钥 | 被拒绝；实际认证指纹不匹配 |
| 用下载的新私钥新建连接 | 实际认证成功，提交后服务器临时私钥已删除 |
| 复用发起操作的原连接确认 | 被拒绝 |
| 两次独立连接切换 root | 第一次确认后禁用密码，第二次确认后提交，仅公钥认证生效 |
| 其他用户策略 | 对 nobody 的完整 `sshd -T -C` 输出前后相同 |
| 仅密钥阶段无人确认 | 真实 systemd timer 到期自动恢复原配置，原密钥可建立新连接 |
| 生成后无人下载 / 确认 | 真实 systemd timer 到期撤销新增公钥、清理临时私钥，原密钥仍可建立新连接 |
| 测试收尾 | 主配置和原授权公钥逐字节恢复，无待确认操作和残留测试私钥 |

首次实机定时器测试发现整秒 `OnCalendar` 与小数截止时间的边界问题：定时器可能提前不到一秒触发，程序忽略后不再执行。已改为向上取整并在过早回调时重新登记 timer，增加回归测试后重新完成实机超时测试。

测试用私钥通过已有 SSH 连接直接写入电脑的受限临时文件，没有输出到终端或纳入操作备份。测试结束删除电脑上的测试私钥，保留原本的本地登录私钥。服务器保留工具程序和受限的操作记录，方便查看恢复过程。

## 实测边界

真实系统覆盖 Debian 12；Ubuntu、其他 Debian 版本及各类 FinalShell 私钥格式未逐一实测。没有重启 VPS，重启后的回退行为通过 `Persistent=true` 的日历 timer 配置和重建 Manager 的测试验证，不能视为实机重启验收。私钥口令使用系统 ssh-keygen 的交互输入；没有在自动测试中模拟所有客户端的口令提示。

本地辅助控制程序、批量 VPS 管理和全用户统一切换不属于第一版。首版发布标签为 `sshkeytool-v0.1.0`，包含独立安装器、程序、文档和校验文件；stone-hk 已装好独立工具和新版统一入口。
